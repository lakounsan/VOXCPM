# 🎙️ Studio0808 VoxCPM — កម្មវិធីសំយោគសំឡេង AI (Text-to-Speech)

![GitHub License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)
![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)
![Platform](https://img.shields.io/badge/platform-windows-lightgrey.svg)
![Languages](https://img.shields.io/badge/UI_Languages-English%20%7C%20ភាសាខ្មែរ%20%7C%20繁體中文-orange.svg)

កម្មវិធីកុំព្យូទ័រក្រៅបណ្តាញ (Offline Desktop GUI) ដ៏ទំនើប ដែលបង្កើតឡើងផ្អែកលើ **VoxCPM2** របស់ OpenBMB — ម៉ូដែលភាសាធំសំយោគសំឡេងកូដចំហដែលមានទំហំ ២ ពាន់លានប៉ារ៉ាម៉ែត្រ (2B parameters)។ កម្មវិធីនេះរួមបញ្ចូលការរចនាសំឡេង (Voice Design), ការក្លូនសំឡេងរហ័ស (Voice Clone), ការក្លូនកម្រិតខ្ពស់ (Ultimate Clone) និងបន្ទប់ថតសំឡេងផ្ទាល់ក្នុងពេលជាក់ស្តែង (Live Recording Studio) ដោយមិនចាំបាច់សរសេរកូដសូម្បីតែមួយជួរ។ គាំទ្រចំណុចប្រទាក់ជាភាសា **ខ្មែរ (Khmer)**, **អង់គ្លេស (English)** និង **ចិន (繁體中文)**។

## 🌐 ការប្តូរភាសាក្នុងកម្មវិធី (Language Switching)

អ្នកអាចប្តូរភាសានៅជ្រុងខាងឆ្វេងផ្នែកខាងក្រោមនៃរបារចំហៀងបានគ្រប់ពេល៖
* **ភាសាខ្មែរ (Khmer)** — ចំណុចប្រទាក់ជាភាសាខ្មែរពេញលេញ រួមទាំងគំរូសំឡេងខ្មែរ (លោកតា, លោកយាយ, បុរសវ័យក្មេង, ស្ត្រីវ័យក្មេង, ក្មេងប្រុស, ក្មេងស្រី)។
* **English** — ចំណុចប្រទាក់ជាភាសាអង់គ្លេសស្ដង់ដារអន្តរជាតិ។
* **繁體中文 (Traditional Chinese)** — ចំណុចប្រទាក់ដើមជាភាសាចិន។

អ្នកក៏អាចបើកកម្មវិធីជាភាសាខ្មែរដោយផ្ទាល់តាមរយៈ៖
```bash
# បើកជាភាសាខ្មែរ
python Studio0808_VoxCPM.py --lang km
# ឬចុចពីរដងលើឯកសារ: run_khmer.bat

# បើកជាភាសាអង់គ្លេស
python Studio0808_VoxCPM.py --lang en
# ឬចុចពីរដងលើឯកសារ: run_english.bat
```

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

### 1. 🎤 បន្ទប់ថតសំឡេងផ្ទាល់ (Live Voice Recording Studio)
* **ការជ្រើសរើសមីក្រូហ្វូន** — រកឃើញ និងរាយនាមឧបករណ៍បញ្ចូលសំឡេង (Microphone) ទាំងអស់ក្នុងប្រព័ន្ធកុំព្យូទ័ររបស់អ្នកដោយស្វ័យប្រវត្តិ។
* **រលកសំឡេងក្នុងពេលជាក់ស្តែង (Real-Time Waveform)** — បង្ហាញចលនារលកសំឡេងពណ៌ផ្កាឈូកនៅពេលកំពុងថត ផ្តល់ទំនុកចិត្តថាឧបករណ៍កំពុងចាប់សំឡេងបានយ៉ាងល្អ។
* **ចុចម្តងដើម្បីប្រើប្រាស់ (One-Click Apply)** — បន្ទាប់ពីថតរួច អ្នកអាចចុចប៊ូតុងដើម្បីបញ្ជូនឯកសារ WAV និងអត្ថបទដែលបានអានទៅកាន់ផ្ទាំង «ក្លូនសំឡេង» ឬ «ក្លូនកម្រិតខ្ពស់» ភ្លាមៗ។

### 2. ✨ ការរចនាសំឡេង (Voice Design)
* **បង្កើតសំឡេងថ្មីដោយគ្មានសំឡេងយោង** — មិនត្រូវការឯកសារសំឡេងយោងឡើយ។ គ្រាន់តែបន្ថែមការពណ៌នាជាភាសាអង់គ្លេសក្នុងវង់ក្រចកនៅដើមអត្ថបទ (ឧ. `(A gentle young female voice, smiling)`) នោះម៉ូដែលនឹងបង្កើតសំឡេងថ្មីដែលត្រូវគ្នានឹងការពណ៌នាទាំងស្រុង។
* **ផ្ទាំងគំរូសំឡេងរហ័ស** — មានគំរូសំឡេងស្រាប់ៗសម្រាប់ភាសាខ្មែរ, អង់គ្លេស, ចិន, ជប៉ុន និងកូរ៉េ។
* **📋 សំយោគជាបាច់ (Batch Synthesis / Audiobook)** — អាចបិទភ្ជាប់អត្ថបទវែង ឬប្រលោមលោកដោយបំបែកមួយជួរមួយប្រយោគ ប្រព័ន្ធនឹងដំណើរការសំយោគតាមជួរជាឯកសារដាច់ដោយឡែកនៅផ្ទៃខាងក្រោយ ការពារការអស់អង្គចងចាំ (Memory Overflow)។

### 3. 👥 ការក្លូនសំឡេងរហ័ស (Voice Clone)
* **ប្រើសំឡេងយោងខ្លីបំផុត** — ត្រូវការតែសំឡេងនិយាយច្បាស់ពី ៣ ទៅ ១០ វិនាទីប៉ុណ្ណោះ ដើម្បីចម្លងទឹកដម និងចរិតលក្ខណៈសំឡេងរបស់អ្នកនិយាយ។
* **ការផ្លាស់ប្តូរធម្មជាតិ** — លំនាំដើមរក្សាគ្រាប់ពូជចៃដន្យបើកចំហ៖ ទឹកដមសំឡេងនៅដដែល ប៉ុន្តែចង្វាក់ដង្ហើម និងការបញ្ចេញសំឡេងនឹងមានភាពខុសគ្នាបន្តិចបន្តួចរាល់ពេលបង្កើត ជួយឱ្យអ្នកអាចជ្រើសរើសសំឡេងដែលធម្មជាតិបំផុត។

### 4. 👑 ការក្លូនកម្រិតខ្ពស់ (Ultimate Clone)
* **ការបន្តសំឡេងដោយរលូនឥតខ្ចោះ** — ផ្តល់ទាំងឯកសារសំឡេងយោង និងអត្ថបទដើមដែលបាននិយាយក្នុងសំឡេងនោះ។ ម៉ូដែលនឹងបន្តការនិយាយប្រយោគថ្មីរបស់អ្នកដោយរក្សាអារម្មណ៍ ចង្វាក់ដកដង្ហើម និងទឹកដមសំនៀងដើមបានយ៉ាងរលូន ១០០%។

## 🚀 ការចាប់ផ្តើមរហ័ស (Quick Start)

```bash
git clone https://github.com/begin0808/VoxCPM2.git

```

### 2. ដំឡើងបណ្ណាល័យដែលត្រូវការ
```bash
pip install -r requirements.txt
```

```bash

# ឬបើកជាភាសាខ្មែរដោយផ្ទាល់
python Studio0808_VoxCPM.py --lang km
```

## 📂 ការដំឡើងម៉ូដែល (Model Deployment)

កម្មវិធីនេះដំណើរការ **ក្រៅបណ្តាញទាំងស្រុង (Fully Offline)** — គ្មានទិន្នន័យសំឡេង ឬអត្ថបទណាមួយត្រូវបានបញ្ជូនទៅកាន់ Cloud ឡើយ។

1. បើកកម្មវិធី ហើយចូលទៅកាន់ផ្ទាំង **«ការកំណត់» (Settings)**។
2. ជ្រើសរើសប្រភពទាញយក (Download Mirror):
   * **Hugging Face ផ្លូវការ** (ណែនាំសម្រាប់តំបន់ភាគច្រើន — ល្បឿនលឿន)
   * **ModelScope / Mirror** (សម្រាប់តំបន់ដែលមានបញ្ហាក្នុងការតភ្ជាប់)
3. ចុច **«ចាប់ផ្តើមទាញយក / ពិនិត្យម៉ូដែល»**។
4. ប្រព័ន្ធទាញយកគាំទ្រ **HTTP Range (អាចបន្តការទាញយកបានពេលដាច់អ៊ីនធឺណិត)**។ នៅពេលទាញយករួចរាល់ កម្មវិធីអាចដំណើរការដោយមិនចាំបាច់មានអ៊ីនធឺណិតជារៀងរហូត។
